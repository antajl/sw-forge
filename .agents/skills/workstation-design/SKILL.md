# SW-Forge — Workstation Design System

## Aesthetic Principles

- **Стиль:** Аналитическая рабочая станция высокой плотности данных (Data-Dense Workstation / Bloomberg Terminal aesthetic).
- **Никаких эмодзи** в интерфейсе и системных панелях — только **Lucide SVG иконки**.
- **Никаких неоновых градиентов** и ядовитых теней: строгие матовые графитовые поверхности (`--bg-surface`, `--bg-subtle`).
- **Шрифт и цифры:** Сан-серифная типографика с обязательным свойством `font-variant-numeric: tabular-nums` для всех числовых колонок рун, статов и эффективности.
- **Тонкие рамки:** разделители 1px полупрозрачные (`var(--border-default)`), без тяжеловесных объемных рамок.
- **Чистая консоль (Zero Console Noise):** Никаких отладочных `console.log` на проде, ошибок 404 по ассетам или циклических таймеров рендера.

## Правила компонентов

1. **Кнопки (`.btn`, `.monsters-selection-btn`):**  
   `inline-flex`, аккуратный скругленный контур (4-6px), центрированная Lucide SVG иконка + текст, плавная смена прозрачности при ховере.
2. **Таблицы рун и артефактов:**  
   Виртуализированный скролл с `OVERSCAN = 8`, фиксированные высоты строк, отсутствие пересчета `getBoundingClientRect` на каждый кадр скролла.
3. **Всплывающие подсказки (Tooltips):**  
   Легковесные плавающие подсказки через `position: fixed` с кэшированием позиции. Никаких мерцаний при движении курсора.
